# Fluid Foldkit catalog

Install editable native Foldkit source with the standard shadcn CLI. Tailwind CSS v4 is required. React and components.json are not required.

- [KeyCap](https://fff.timhanlon.com/docs/key-cap.md): Shared filled keyboard caps with semantic kbd elements, combo splitting and inverted tone. [Craft](craft.md#key-cap).
- [MessageScroller](https://fff.timhanlon.com/docs/message-scroller.md): A native conversation viewport with following, anchored turns and an animated return-to-latest control. [Craft](craft.md#message-scroller).
- [ContextMenu](https://fff.timhanlon.com/docs/context-menu.md): The shared Dropdown tree opened at a pointer or focused trigger, with native text-field menus and return focus. Requires the guide's pnpm compatibility step. [Craft](craft.md#context-menu).
- [CodeBlock](https://fff.timhanlon.com/docs/code-block.md): Code and command output with copy feedback, optional line numbers, caller-owned highlighting and shared scrollbars. [Craft](craft.md#code-block).
- [Confirmation](https://fff.timhanlon.com/docs/confirmation.md): Inline approval questions composed from Banner with parent-owned requested, approved and denied states. [Craft](craft.md#confirmation).
- [Breadcrumb](https://fff.timhanlon.com/docs/breadcrumb.md): Navigation trails with shared hover, sibling menus, truncation tooltips and responsive collapse. Requires the guide's pnpm compatibility step. [Craft](craft.md#breadcrumb).
- [Button](https://fff.timhanlon.com/docs/button.md): A stateless button with variants, sizes and shapes. [Craft](craft.md#button).
- [Select](https://fff.timhanlon.com/docs/select.md): A controlled selection with keyboard navigation and a portalled popup. [Craft](craft.md#select).
- [DatePicker](https://fff.timhanlon.com/docs/date-picker.md): A date selection composed with Calendar and a portalled popup. [Craft](craft.md#date-picker).
- [Checkbox](https://fff.timhanlon.com/docs/checkbox.md): A controlled checkbox with visible and accessible labels. [Craft](craft.md#checkbox).
- [Switch](https://fff.timhanlon.com/docs/switch.md): A controlled switch with keyboard and pointer interaction. [Craft](craft.md#switch).
- [Combobox](https://fff.timhanlon.com/docs/combobox.md): Single and multiple selection with filtering and editable chips. Requires the guide's pnpm compatibility step. [Craft](craft.md#combobox).
- [Dropdown](https://fff.timhanlon.com/docs/dropdown.md): Action menus with keyboard navigation and configurable popup content. Requires the guide's pnpm compatibility step. [Craft](craft.md#dropdown).
- [Input](https://fff.timhanlon.com/docs/input.md): Controlled text and number inputs with native stepping and file selection callbacks. [Craft](craft.md#input).
- [Textarea](https://fff.timhanlon.com/docs/textarea.md): A controlled multiline text field with sizing and validation attributes. [Craft](craft.md#textarea).
- [Badge](https://fff.timhanlon.com/docs/badge.md): A presentation badge with colors, solid and dot variants, sizes and corners. [Craft](craft.md#badge).
- [Field](https://fff.timhanlon.com/docs/field.md): Accessible field composition with labels, descriptions and validation messages. [Craft](craft.md#field).
- [InputCopy](https://fff.timhanlon.com/docs/input-copy.md): Copyable values with clipboard feedback and an optional portalled tooltip. [Craft](craft.md#input-copy).
- [InputGroup](https://fff.timhanlon.com/docs/input-group.md): A group of labelled input fields with shared hover, sizing and corners. [Craft](craft.md#input-group).
- [Card](https://fff.timhanlon.com/docs/card.md): Selectable and dismissible cards with compound content and grouped hover. [Craft](craft.md#card).
- [Banner](https://fff.timhanlon.com/docs/banner.md): Animated status banners with dismissal and retained exits. [Craft](craft.md#banner).
- [CarouselDots](https://fff.timhanlon.com/docs/carousel-dots.md): Controlled slide indicators with optional autoplay and progress. [Craft](craft.md#carousel-dots).
- [ThinkingIndicator](https://fff.timhanlon.com/docs/thinking-indicator.md): An accessible thinking status with scoped cycling visuals. [Craft](craft.md#thinking-indicator).
- [ThinkingSteps](https://fff.timhanlon.com/docs/thinking-steps.md): Controlled reasoning disclosure with progressive step content. [Craft](craft.md#thinking-steps).
- [Accordion](https://fff.timhanlon.com/docs/accordion.md): Keyboard-accessible single or multiple disclosure. [Craft](craft.md#accordion).
- [CheckboxGroup](https://fff.timhanlon.com/docs/checkbox-group.md): Controlled checkboxes with shared hover and keyboard navigation. [Craft](craft.md#checkbox-group).
- [RadioGroup](https://fff.timhanlon.com/docs/radio-group.md): Controlled single selection with roving keyboard focus. [Craft](craft.md#radio-group).
- [Tabs](https://fff.timhanlon.com/docs/tabs.md): Controlled tabs with manual keyboard activation and parent-owned panels. [Craft](craft.md#tabs).
- [Slider](https://fff.timhanlon.com/docs/slider.md): Controlled scalar and range sliders with lifted drag subscriptions. [Craft](craft.md#slider).
- [Tooltip](https://fff.timhanlon.com/docs/tooltip.md): Accessible portalled tooltip with delayed visibility and retained exits. [Craft](craft.md#tooltip).
- [Calendar](https://fff.timhanlon.com/docs/calendar.md): Controlled date-range selection with restrictions and keyboard navigation. [Craft](craft.md#calendar).
- [ColorPicker](https://fff.timhanlon.com/docs/color-picker.md): Inline and popover color editors with channel controls and swatches. Requires the guide's pnpm compatibility step. [Craft](craft.md#color-picker).
- [Dialog](https://fff.timhanlon.com/docs/dialog.md): Native modal composition with scoped isolation, focus and retained exits. [Craft](craft.md#dialog).
- [Sidebar](https://fff.timhanlon.com/docs/sidebar.md): Composable responsive navigation with collapse, resize, groups and mobile drawers. [Craft](craft.md#sidebar).
- [CommandMenu](https://fff.timhanlon.com/docs/command-menu.md): Searchable commands and a keyboard-opened modal palette. [Craft](craft.md#command-menu).
- [Table](https://fff.timhanlon.com/docs/table.md): Semantic tables with controlled sorting, empty states and scoped row hover. [Craft](craft.md#table).
- [DataTable](https://fff.timhanlon.com/docs/data-table.md): TanStack row models with Foldkit sorting, filters, selection, inline editors, column layout and pagination. Requires the guide's pnpm compatibility step. [Craft](craft.md#data-table).
- [ChatMessage](https://fff.timhanlon.com/docs/chat-message.md): Conversation bubbles with owned file previews and consumer actions. [Craft](craft.md#chat-message).
- [InputMessage](https://fff.timhanlon.com/docs/input-message.md): Controlled composer with attachments, suggestions, history and queued messages. [Craft](craft.md#input-message).
- [AskUserQuestions](https://fff.timhanlon.com/docs/ask-user-questions.md): Stateful question flows with validated answers and completion events. [Craft](craft.md#ask-user-questions).

ScrollArea is a shipped helper with an external recipe at /docs/scrollbars.md. FileThumbnail and QueuedStack ship through conversation components. Other system pages declare reference-only status; do not guess upstream React registry names.
