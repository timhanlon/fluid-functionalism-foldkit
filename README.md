# Fluid Functionalism Foldkit

A port of [Micka Touillaud](https://x.com/micka_design)'s [Fluid Functionalism](https://www.fluidfunctionalism.com/) to Foldkit, completed mostly by GPT-6.1 Sol, with some input from Opus 5.5, over the course of about a week.

Thanks to Micka for his blessing to release this, and Devin Jameson for his encouragement and feedback.

Demo site is at [fff.timhanlon.com](https://fff.timhanlon.com).

## Caveats

- For a jank-free experience, you’ll need to patch Foldkit - see [PR #1711](https://github.com/foldkit/foldkit/pull/1711) & a [repro courtesy of Opus 5.5](https://github.com/timhanlon/foldkit-perf)
- The Breadcrumb, ColorPicker, Combobox, and Dropdown components require a patch to Foldkit UI
- I have not read the code yet
